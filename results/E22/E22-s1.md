# E22: what score identifies membership in a schema?

Level-1 SAGE schemas over 10 noisy instances per template (severity 1; θ = 0.4 + sleep; seed 1). Test cases: one fresh instance of each stored template (≤ 500) and 250 instances of absent templates. Each score picks the best of the fingerprint top-16 schemas (≥ 2 members); the decision is *correct* if that schema's majority template is the case's template. Recall = correct acceptances / present-template cases. Core = schema facts with probability ≥ 0.7.


## T = 100 templates (1000 memory cases; 139 schemas with ≥ 2 members; 350 tests)

| score | best-schema correct (any threshold) | AUC correct vs wrong | recall at precision ≥ 0.9 | recall at precision ≥ 0.95 |
|---|---|---|---|---|
| symmetric FAC (SAGE default) | 0.940 | 0.965 | 0.780 | 0.760 |
| coverage S(g→x)/S(g→g) | 0.950 | 0.940 | 0.610 | 0.380 |
| core fraction (p ≥ 0.7) | 0.820 | 0.855 | 0.000 | 0.000 |
| √(core × symmetric) | 0.910 | 0.950 | 0.690 | 0.550 |

Mean core size 5.1 facts (343.4ms).
