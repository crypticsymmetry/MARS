# E11: inference quality and calibration with corroboration

100 hidden templates × 10 noisy instances in memory (perturbation severity 2, 2 distractors); 450 queries = fresh instances with one root higher-order fact deleted. Inferences are projected from each of the top-m analogues (fused retrieval); *support* = number of analogues proposing the inference. An inference is *true* if it is a fact of the query's undeleted instance.
